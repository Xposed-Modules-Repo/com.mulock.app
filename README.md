# 多用户应用锁

## 功能介绍

需要 Root + Zygisk + LSPosed。管理器只安装在 User 0。

- 应用冻结，支持息屏立即冻结和延时冻结。
- 按 Android UserId + 包名区分多开应用，可只锁定其中一个用户的应用。
- 隐藏指定用户应用的桌面图标，隐藏后仍可后台运行和接收消息。
- 通用通知伪装，可设置名称、标题、内容、图标和声音。
- 可阻止通知点击、小窗、气泡和长按操作。
- 伪装通知对应的应用打开后自动清除通知。
- 通知声音自定义。
- 桌面底部左、右手势可启动两个隐藏应用。
- 支持图案、数字密码以及两枚指定指纹解锁。
- 隐藏手势启动应用的任务列表记录。
- 受保护应用使用中息屏后可重新上锁并返回桌面。
- 冻结抽屉可集中显示、解冻并启动冻结应用。
- 卸载保护需验证管理密码或已设置的指纹后临时放行。

## 设计初衷

本软件设计初衷是将炼妖壶等工具开启的工作空间中安装的聊天应用完美隐藏，同时不影响后台运行和接收信息。可实现应用图标隐藏、通知信息伪装，并通过桌面底部滑动启动应用。

启动后可使用密码或指定的指纹验证。只有在应用内指定的指纹才能解锁，其他已录入手机系统的非指定指纹无法开启受保护应用，从而规避传统应用锁中“系统录入的任意指纹都可解锁”的漏洞。

通知伪装后，打开对应的聊天应用会自动清除提示信息，下次再出现提示时即可判断收到了新信息。目前可实现较完整的聊天应用隐藏体验。

## 使用方法

1. 只在主空间 User 0 安装正式 APK 并授予 Root 权限。
2. 在 LSPosed 中启用模块。
3. 首次启用时会默认选中所需作用域；确认 `system`、`android`、`com.android.systemui` 三项已选中。
4. 重启手机，再打开管理器完成首次规则同步。
5. 根据需要设置桌面隐藏、通知伪装、应用锁和底部手势。
