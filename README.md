# 多用户应用锁

## 功能介绍

需要 Root + LSPosed。

- 应用冻结，支持立即冻结、延时冻结。
- 多开应用可指定其中一个上锁。
- 应用桌面图标隐藏。
- 通知伪装。
- 伪装通知对应的应用打开后自动清除通知。
- 通知声音自定义。
- 隐藏的应用可通过指定手势打开。
- 指定指纹解锁上锁的应用。
- 隐藏的应用不在任务列表显示。
- 隐藏的应用如果正在使用，锁屏后会返回桌面，解锁手机后显示桌面。

## 设计初衷

本软件设计初衷是将炼妖壶等工具开启的工作空间中安装的聊天应用完美隐藏，同时不影响后台运行和接收信息。可实现应用图标隐藏、通知信息伪装，并通过桌面底部滑动启动应用。

启动后可使用密码或指定的指纹验证。只有在应用内指定的指纹才能解锁，其他已录入手机系统的非指定指纹无法开启受保护应用，从而规避传统应用锁中“系统录入的任意指纹都可解锁”的漏洞。

通知伪装后，打开对应的聊天应用会自动清除提示信息，下次再出现提示时即可判断收到了新信息。目前可实现较完整的聊天应用隐藏体验。

## 使用方法

1. 安装正式 APK。
2. 在 LSPosed 中启用模块。
3. 首次启用时会默认选中所需作用域；确认 `system`、`android`、`com.android.systemui` 三项已选中。
4. 重启手机，再打开管理器完成首次规则同步。
5. 根据需要设置桌面隐藏、通知伪装、应用锁和底部手势。
