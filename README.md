# 多用户应用锁

面向 Android 多用户、工作空间及应用分身场景的 LSPosed 应用保护模块。规则以 `UserId + PackageName` 为单位保存，同一应用安装在 user 0、user 10、user 999 等空间时可以分别控制，互不影响。

## 主要功能

- 多用户应用锁：支持数字密码、九宫格手势和指定的两个系统指纹。
- 桌面图标隐藏：只隐藏指定用户空间中的应用入口，应用仍可在后台运行并接收消息。
- 通知伪装：可替换通知名称、标题、内容、图标和声音，并可阻止通知操作及打开应用后自动清除通知。
- 桌面底部手势：左右区域分别启动指定用户空间的应用，可选择不在最近任务列表显示。
- 应用冻结：支持息屏立即冻结或延时冻结，并提供桌面冻结应用抽屉。
- 应用锁失焦、息屏及最近任务重新上锁。
- 卸载保护及授权设备解绑。

## 使用场景

适用于炼妖壶、工作资料、系统多用户及厂商应用分身中安装的聊天应用。可隐藏桌面入口和真实通知，同时保留后台消息接收；需要使用时从桌面底部手势启动并完成独立密码或指定指纹验证。

## 环境要求

- Android 8.0 及以上；不同系统定制程度较高，具体兼容性以实机为准。
- Root。
- Zygisk / LSPosed 环境。
- 模块管理应用仅安装在 user 0。

## 安装和启用

1. 安装正式 APK。
2. 在 LSPosed 中启用模块。
3. 作用域至少勾选“系统框架（Android System）”。
4. 根据通知伪装和桌面隐藏功能的页面提示，勾选 SystemUI、桌面或目标应用作用域。
5. 重启手机后打开模块进行配置。
