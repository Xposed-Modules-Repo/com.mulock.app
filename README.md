# 多用户应用锁

需要 Root + Zygisk + LSPosed。软件只需安装在主空间 User 0，可统一管理 User 0、User 10、User 999、工作资料和其他 Android 用户中的应用。

同一个应用安装在多个 User 时可分别设置。例如只隐藏和上锁 User 999 的微信，User 0 和 User 10 的微信不受影响。

## 设计用途

用于隐藏炼妖壶、工作资料或其他多开空间中安装的聊天应用，同时保留后台运行和消息接收。可隐藏图标、伪装通知、隐藏任务列表，再通过桌面底部手势启动，使用密码或指定指纹解锁。

## 全部功能

### 多用户应用列表

- 在 User 0 查看和管理所有 Android User 安装的应用。
- 同包名不同 User 分开显示和设置。
- 扫描后保存应用列表，日常打开直接读取上次结果。
- 可手动重新扫描，已开启的应用优先显示。
- 支持按应用名、包名和 User 搜索。

### 应用锁

- 可单独锁定某个 User 的应用。
- 支持“切换应用后上锁”开关。
- 支持“从最近任务进入时上锁”开关。
- 支持“锁屏后重新上锁”开关。
- 首次打开只验证一次，应用内打开分享、文件、网页或其他内部页面不重复验证。
- 只有已开启应用锁的应用在使用中息屏时，才会重新上锁并返回桌面。

### 解锁方式

- 9 点手势密码。
- 数字密码。
- 指定指纹解锁。
- 可指定两枚已录入系统的指纹，方便左右手使用。
- 只有软件内指定的指纹可以解锁受保护应用，其他虽可解锁手机的指纹不能解锁应用锁。
- 应用锁和随心隐藏共用同两枚指定指纹。

### 桌面图标隐藏

- 可隐藏指定 User 的应用图标。
- 隐藏图标不会卸载或停止应用。
- 隐藏后仍可后台运行和接收消息。
- 重启后继续保持隐藏。
- 桌面刷新后尽量保持原来的桌面页面。

### 随心隐藏

- 锁屏时自动隐藏已选应用图标。
- 使用指定指纹解锁手机后，图标自动显示。
- 使用密码、人脸或非指定指纹解锁后，图标仍然隐藏。
- 应用内进行指纹验证不会触发图标显示。

### 隐藏应用锁自身

- 首页右上角设置提供“隐藏应用锁自身”开关。
- 开启前先测试恢复入口，测试通过后才隐藏图标。
- 在系统拨号盘完整输入 `*#6688#`，输入最后一个 `#` 后自动打开软件。
- 拨号入口不会跳过管理密码。
- 使用前需在 LSPosed 中勾选当前系统拨号器并重启。

### 任务列表隐藏

- 可隐藏通过底部手势启动的应用任务记录。
- 左右两个底部手势共用一个任务列表隐藏开关。

### 系统应用列表隐藏

- 可在系统设置的已安装应用列表中隐藏已选应用。

### 更多隐藏范围

以下各项均有独立开关：

- 在权限、通知、后台管理和特殊访问等系统管理页隐藏。
- 在流量使用、流量控制、电量和省电页隐藏。
- 在分享、打开方式和快速分享列表隐藏。
- 减少普通第三方应用通过常见应用查询发现已隐藏应用。

这些功能只隐藏常见系统界面和应用查询中的显示结果，不删除应用，不修改真实流量或电量数据。Root、ADB 和专用检测工具仍可发现应用。

### 桌面底部手势启动

- 左、右两个手势区可分别设置一个应用，最多快速启动两个隐藏应用。
- 左侧从中间向左滑，右侧从中间向右滑。
- 只在桌面响应，不影响应用和输入法操作。
- 手势区高度和最小滑动距离可调节。
- 设置时可显示手势触发区域。
- 支持指定 User 启动应用。
- 若目标应用已冻结，启动前自动解冻。

### 通知伪装

- 每个 User 的应用分开设置，不会影响其他 User 的同名应用。
- 可自定义伪装应用名。
- 可自定义通知标题和正文。
- 可自定义状态栏小图标和通知列表图标。
- 可保留原通知声音、设为静音或选择自定义声音。
- 只修改开启通知伪装的应用，不影响来电、系统提示和其他应用的声音。
- “阻止通知操作”可阻止通知点击、按钮、长按设置、小窗、气泡和横幅。
- “自动清除通知”开启后，打开对应 User 的应用即自动清除伪装通知，下次再出现时即可判断收到了新消息。

### 应用冻结（永久免费）

- 息屏后立即冻结。
- 息屏 X 分钟后延时冻结。
- 亮屏时取消尚未执行的延时冻结。
- 各 User 的同名应用分开冻结。
- 启动被冻结应用前自动解冻。
- 可将“冻结抽屉”添加到桌面，用四列图标集中显示、解冻和启动冻结应用。
- 应用锁自身不会被加入冻结列表。

### 卸载保护（免费）

- 阻止从桌面或系统设置直接卸载应用锁。
- 在应用内使用已设置的密码或指纹验证后，开放 2 分钟卸载时间。
- 验证后会提示前往系统应用管理页卸载。

### 授权中心（免费）

- 显示剩余免费体验时间。
- 体验到期后只停止 VIP 功能，免费功能继续使用。
- 支持输入授权码激活。
- 一个授权码同时只绑定一台手机。
- 用户可自助解绑旧手机，再在新手机上激活。
- 购买授权请联系微信：`WX3097964364`。

### 活动公告

- 首页顶部可滚动显示活动公告、优惠、价格和其他通知。
- 无公告时不占用首页空间。

### 自动问题诊断

- 默认开启，可在首页右上角设置中关闭。
- 自动检查用户已开启的各项功能。
- 只有检测到问题时才限频上报，正常使用时不持续上传。
- 首次安装还没有启用 LSPosed 或重启时，不作为软件故障上报。
- 支持“重新检测”和“日志上报”两个独立操作。
- 问题复现后可填写微信号手动上报，方便配合调试。
- 不上传密码、手势轨迹、指纹数据或通知正文。

### 版本检测

- 首页自动检查新版本。
- 首页右上角设置可手动检测更新。
- 更新弹窗内容可复制。
- 点击下载只打开软件设置的下载链接。

### 首页和设置

- 首页按“免费功能”和“VIP 功能”分类显示。
- 各项功能分开设置，应用列表直接显示开关。
- 通知伪装可点击应用进入单独设置。
- 正常打开软件进入首页，桌面冻结抽屉快捷方式进入冻结抽屉。
- 右上角设置包含自动问题诊断、隐藏应用锁自身、检测更新和关于/当前版本。
- 首页显示 Root 和 LSPosed 激活状态。

## 安装方法

1. 只在主空间 User 0 安装 APK，并授予 Root 权限。
2. 在 LSPosed 中启用模块。
3. 确认 `system`、`android`、`com.android.systemui` 三个基础作用域已选中。
4. 如需隐藏应用锁自身，还需勾选系统拨号器。
5. 部分手机的通知伪装需要将目标应用加入 LSPosed 作用域，请按软件诊断提示设置。
6. 重启手机。
7. 打开软件扫描应用，再开启所需功能。
